# 動きの決まり

画面の切り替え・窓の開閉・押したときの反応の基準。iPhone（iOS）の動きを基準にする。

## 作り（押した瞬間に動ける理由）
iPhone のアプリや、ブラウザで動く業務アプリと同じく、**枠は作り置き、データは裏で先に持ち、押した物だけを表に出す**。
- **ページを読み直さない**：左のメニュー・重なる窓・通知は一度だけ作って残し、画面を移るときは中身（.main と画面の窓）だけを差し替える（[router.js](../public/assets/js/router.js)）。各画面の処理は `export default async function mount()` の中にあり、開くたびに呼ぶ。
- **画面の部品を先に持つ**：画面が出たら、手の空いた時間に、そこから移れる画面の HTML・CSS・JS を読んでおく（患者のデータは入っていない）。
- **データを押した瞬間に引く**：行・リンクを押し下げた瞬間（離す前。Enter も）に、その画面が前に開いたときに引いた通信を引き始める。マウスを乗せただけでは患者のデータは引かない（閲覧記録が残るため）。
- **重なる窓の中身も押し下げた瞬間に読む**：見えない置き場で読み、開くときに読み込んだまま窓へ移す（`moveBefore` は iframe を読み直さない）。
- **窓は押した瞬間に開く**：窓に出すもの（テンプレート・指導内容の提案）は、画面を開いたとき・来局を選んだときに裏で用意しておく。大きな窓は、画面が出た後に一度だけ見えない形で描いておく（初めて描くときは文字の形を作るのに数コマかかる）。
- **動かすのは形（transform）と透明度（opacity）だけ**：描き直しが要らず、画面を描く処理と別に動くので、重い画面でもコマが落ちない。背景のぼかし（backdrop-filter）・角の切り抜き（clip-path）は毎コマ描き直しになるので動かさない。

## 守ること
1. **押してから動き出すまで 0.1秒より短く。** 新しい画面のデータを待つのは 0.06秒まで。そろえば描き終わった画面ごと動かし、遅れたら骨組み（上の帯・パンくず・下の操作バー）で動き出して、中身はそろったところで一度に浮かび上がらせる。部品を1つずつ出すことはしない。
2. **崩れた途中の画面・空の枠・2つの画面の二重写りを見せない。** 切り替えは「上の板が下の板を覆う」形にし、画面（.main）には背景色を持たせる。同じ画面を開き直すとき（保存した後）は、新しい内容がそろった瞬間に入れ替える。
3. **動きで場所の関係を示す。**
   - 進む：次の画面が右端から全面せり出し、前の画面は左へ30%下がって暗く（明るさ0.8）。戻るは逆。左のメニューは動かさず一番手前。
   - 左のメニューで移る：メニューの並びの向き（下の項目なら下から）に全面せり出す。前の画面は18%下がって暗く。
   - 窓：押した物（ボタン・行・札・箱）の中に収まる大きさで、窓全体を不透明のまま縮めた形から広がり、閉じると同じ形へ縮んで、縮み切るところで消える。背景の暗さは窓と同じ長さ・同じ曲線で変える。
   - 押して画面を移る行・札・メニューには、押し下げた瞬間に押した跡を付ける。
4. **押したら必ず応える。** 押した物は小さく潰れて戻る。
5. **動きを減らす設定では動かさない。**

## 曲線と長さ
Apple のばね（WWDC23「Animate with springs」）：剛性 (2π/d)²、減衰比 1 − bounce。CSS の `linear()` に d の1.6倍まで点を打って近似する（残りが目に見えない所まで。短く切ると最後に一段跳ぶ）（[scripts/spring-curves.js](../scripts/spring-curves.js)）。

| 用途 | d | bounce | CSS の長さ |
|---|---|---|---|
| 進む・戻る・メニューの切り替え（--spring-nav） | 0.45秒 | 0（画面は跳ねさせない） | 0.72秒 |
| 窓を開く（--spring-open） | 0.5秒 | 0.12（物は少しだけ弾む） | 0.8秒 |
| 窓を閉じる（--spring-close） | 0.36秒 | 0 | 0.576秒（0.26秒から0.12秒で消す） |
| 押したときの潰れ | — | — | 0.16秒 |

**等速（linear・曲線の指定なし）では何も動かさない（2026-11-14 ユーザーの指示）。** 上のばね以外の小さな動きは、app.css の3本の曲線だけを使う。
- 現れる・押したら応える・色が変わる：`--ease-out`（出だしが速く、着地で緩む）
- 消える：`--ease-in`（ゆっくり離れて、速く去る）
- 画面の中で場所を移る・行き来をくり返す：`--ease-in-out`（両端で緩む）
- JS の `animate()` は曲線を書かないと等速になる。段が3つ以上ある動き（潰れて戻る等）は、段ごとに `easing` を書く（全体にかけた曲線は段の中を等速のまま残す）

## 確かめ方
- **数値**：押してから切り替え・窓が始まるまでの時間と、動いている間のコマの間隔（25ms を超えたら1コマ落ち）を測る。長いコマは Long Animation Frames で中身（処理・配置）を分けて見る。
- **目**：動きを記録して、描かれたコマを並べた画像で見る（CDP の screencast。1場面最大60コマ）。
