# 在庫と採用薬（面接で説明するための控え）

2026-11-13 に調べて決めたこと。アプリの範囲は [ワークフロー定義書.md](./ワークフロー定義書.md) の工程7・25。

## 1. 薬の名前の読み方

例：ロスバスタチンOD錠2.5mg「DSEP」

| 部分 | 意味 |
|---|---|
| ロスバスタチン | 成分（一般名） |
| OD錠 | 口の中で溶ける錠剤（口腔内崩壊錠）。ふつうの「錠」とは別の商品 |
| 2.5mg | 1錠の成分量。10mg は4倍の強さ（取り違えると事故） |
| 「DSEP」 | 作っている会社（屋号）。後発品の名前は「一般名＋剤形＋含量＋屋号」と決まっている（平成17年 薬食審査発第0922001号） |

屋号の例：トーワ＝東和薬品、サワイ＝沢井製薬、DSEP＝第一三共エスファ、JG＝日本ジェネリック、KMP＝共創未来ファーマ、YD＝陽進堂、オーハラ＝大原薬品工業、ケミファ＝日本ケミファ。

会社が違っても成分・量・効き目は同じ（先発品と体内での効き方が同じことを示して承認される）。違うのは添加物・大きさ・色・刻印・味・箱・供給の安定。

## 2. どの銘柄を渡すか

- 一般名処方（【般】）：成分・剤形・量が同じなら、どこの会社の物でもよい。薬局が決める
- 銘柄で書かれた処方：「変更不可」の印と医師の署名が無ければ、患者の同意で後発品に変えられる
- 渡した銘柄は、処方箋を出した医療機関に伝える
- 現場は、1成分につき棚に置く銘柄（採用品）を1〜2個に決める。決め方は安定供給・品質・価格・包装（割線・OD錠の有無）。チェーンは本部が決めることが多いと言われる（一次資料では未確認）

## 3. 在庫の流れ（実際の薬局）

| 工程 | 誰が | 何で | 手で打つか |
|---|---|---|---|
| 発注 | 薬局のスタッフ（制度上の決まりは無い。事務でもよい） | 卸の Web 発注（メディパルの Order-epi など）・在庫システムの自動発注（発注点） | 自動発注なら打たない |
| 入荷 | 卸が納品 | 卸の納品データを取り込む | 打たない |
| 出庫 | 自動 | 処方を確定するとレセコンが引く（計算上の在庫＝理論在庫） | 打たない |
| 棚卸 | 薬局のスタッフ | 棚の実物を数え、計算上の数とのずれを直す | ここだけ数える |

納品データで正確になるのは入った数だけ。破損・廃棄・返品・薬局間の小分けの譲渡・数え間違い・粉薬の量り取りのロスはデータに出ないので、棚卸が必ず要る。

## 4. データの形式（標準）

| 区間 | 形式 | 公開 |
|---|---|---|
| 製薬会社 ⇄ 卸 | JD-NET と、製薬協の「業界標準 EDI 統一データフォーマット」（固定長。第8次で1件 250→1000 バイト） | 公開 |
| 卸 ⇄ 薬局・病院 | MEDI-CODE（メディコード社の統一商品コードと発注・納品データの形式。4大卸に使える） | 契約者だけ |
| 卸 ⇄ 薬局（各社の Web） | 卸ごとの Web 発注・CSV | 卸ごと |
| 薬の識別 | 箱の GS1 バーコード（GTIN＋ロット＋期限）。製薬協の形式でも医療用医薬品は GTIN が必須 | 公開 |

## 5. このアプリでやったこと・やらないこと

- **採用薬**：薬局ごとに持つ（adopted_drugs）。薬価照会で Alt+A で付け外し。処方入力の候補で一番上に出す。採用していない薬も候補に残す（供給不足で他の銘柄を使うため）
- **在庫数**：薬局ごとに持つ（drug_stock、単位の 1/1000）。薬の候補・処方の行・薬価照会に出す。処方を保存すると、同じトランザクションで「1日量 × 調剤した日数」を引く。マイナスでも保存は止めない（計算上の数なので）。デモは全部 100 から
- **やらない**：入荷・棚卸・発注。卸と薬局の間の形式が公開されておらず、本物と同じ取り込みが作れない。入荷のたびに箱のバーコードを読む運用は現場に無い

## 6. 想定質問

**Q. 在庫は棚卸まで管理しているのか？**
A. していません。扱うのは「在庫数を見せる」と「処方の保存で引く」だけです。実際の在庫は、入荷を卸の納品データで、出庫を処方の確定で自動に動かし、ずれを棚卸で直します。このうち卸と薬局の間の納品データは MEDI-CODE など契約者向けの形式で公開されていないので、本物と同じ取り込みは作れません。偽の形式で作ると説明できないので、範囲から外しました。

**Q. 在庫の数は正確なのか？**
A. 計算上の数です。処方の保存で引くだけなので、破損・廃棄・返品などで実物とずれます。実際のシステムも同じで、棚卸で直します。だからマイナスになっても保存は止めません。

**Q. 在庫を引くのはどのタイミングか。保存が途中で失敗したら？**
A. 処方の保存と同じ D1 の batch（1つのトランザクション）の中で引きます。明細の途中で失敗すれば、処方も在庫の引き算も全部取り消されます。

**Q. 採用薬はなぜ消さずに上に出すだけなのか？**
A. 後発品の供給不足で採用品が入らないとき、他の銘柄を選ぶ必要があるからです。

**Q. 同じ成分の薬がなぜこんなに多いのか？**
A. 特許が切れた後に各社が後発品を出すからで、名前の「」の中が会社です。成分・量・効き目は同じで、違うのは添加物・形・味・供給です。
